## 처음 한 번
1. 앱을 열면 설정 마법사가 이어집니다: **엔진 설치 → 요약 AI → Google 계정 연결 → 마무리**.
2. 받아쓰기 모델(약 1.6GB)은 처음 설치할 때 함께 내려받습니다.
3. 처음 처리할 때 macOS가 '이동식 볼륨', '마이크', '다운로드 폴더' 접근을 물으면 허용하세요.

## 녹음 넣기
- **DJI 무선 마이크**: 송신기(TX)를 USB로 연결하면 앱이 깨어나 새 녹음을 먼저 Mac에 복사하고 처리합니다. 복사가 끝나면 마이크를 빼도 됩니다. 30분 단위로 나뉜 녹음은 한 회의로 이어 붙입니다. 연결했을 때 바로 처리할지, 물어볼지는 회의록 탭에서 고릅니다.
- **앱에서 녹음**: 회의록 탭에서 상황(대면 회의·온라인 회의·강의 …)과 마이크를 고르고 **녹음 시작**. 온라인 회의는 'Mac 소리도'를 켜면 내 목소리와 상대방 소리를 따로 담아 '나/상대방'을 정확히 나눕니다.
- **Zoom**: '이 컴퓨터에 녹화'한 회의는 끝나고 변환되면 자동으로 가져옵니다. 클라우드 녹화는 Zoom 웹 '내 녹화'에서 내려받기만 하면 다운로드 폴더에서 찾아 회의별로 정리합니다(채팅 파일도 반영).
- **Mac 음성 메모**: 켜 두면 음성 메모 앱에 새 녹음이 생길 때 정리합니다. iPhone 음성 메모도 iCloud로 동기화되면 함께 처리됩니다.
- **파일 처리…**: 갖고 있는 녹음·녹화 파일을 골라 처리합니다.

## 회의록 보기
- 목록에는 **주제 · 시각 · 길이 · 화자 수 · 출처 · 상황**이 보입니다.
- **요약 / 대본**을 누르면 창으로 보고, 옆 복사 버튼은 서식까지 함께 복사합니다(문서·메신저에 그대로 붙여 넣기).
- 오른쪽 클릭으로 **상황을 바꿔 다시 요약**할 수 있습니다.
- 파일은 `~/dji2note/notes/<날짜_시각_이름>/` 에 `summary.md`(요약), `transcript.md`(화자 분리 대본), `raw_whisper.txt`(받아쓰기 원문)로 남습니다.

## 상황별 요약
| 상황 | 요약에 담기는 것 |
|---|---|
| 대면 회의 · 온라인 회의 | 결정 사항, 할 일(담당·기한) |
| 강의·수업 | 핵심 개념, 용어, 예시·실습, 질의응답, 과제 |
| 인터뷰·면접 | 대상자 정보, 질문과 답, 평가 포인트, 처우 논의 |
| 상담·고객 미팅 | 요구·문제, 제안, 합의, 후속 조치 |
| 브레인스토밍 | 아이디어 묶음, 유망안, 리스크, 다음 실험 |
| 발표·세미나 | 핵심 메시지, 인상적인 말, 질의응답 |
| 통화 · 개인 메모 | 요점·약속 / 생각 정리 |

기본은 **자동 판별**(AI가 녹음 앞·가운데·끝을 보고 고름)입니다.

## AI 고르기
| AI | 필요한 것 |
|---|---|
| Claude Code | Claude 구독 계정으로 로그인 (AI 탭의 로그인 버튼) |
| Codex | ChatGPT 계정으로 Codex CLI 로그인 |
| Anthropic · OpenAI · Gemini API | 각 회사의 API 키 |
| Baryon AI | Baryon Labs가 안내한 주소와 키 |
| 사용 안 함 | 없음 — 음량만으로 화자를 나누고 요약은 만들지 않음 |

- **대본 정리 모델**은 글이 길어 빠른 모델, **요약 모델**은 가장 좋은 모델을 권장합니다.
- 무엇이 어디로 가는지는 「데이터·AI 안내」에 적었습니다.

## 연동
- **Google Drive**: 요약과 대본을 Google Docs로 올립니다. '다른 계정 추가…'로 여러 계정을 연결하고 골라 씁니다.
- **Notion**: Notion 통합(내부)을 만들어 토큰을 넣고, 회의록을 모을 페이지 링크를 넣으면 회의마다 페이지가 생깁니다.
- **업무 도구(MCP)**: '회의록 공개'를 켜면 업무 대시보드나 봇이 토큰으로 정리된 회의 요약과 맥락을 가져갈 수 있습니다. '봇에게 줄 연동 안내 복사'로 연결 방법을 그대로 전달하세요. 같은 네트워크·Tailscale 안에서만 닿고, 토큰이 없으면 접근할 수 없습니다.

## 업데이트
- 하루 한 번 새 버전을 확인합니다. 새 버전이 있으면 회의록 탭과 메뉴바에 띠가 뜹니다.
- **업데이트**를 누르면 내려받아 확인(체크섬·서명)한 뒤 앱이 잠깐 꺼졌다 새 버전으로 다시 열립니다. 엔진도 자동으로 같은 버전에 맞춰집니다.
- 정보 탭의 **지금 확인**으로 바로 확인할 수도 있습니다.

## 요약 언어
- 일반 탭 **요약 언어**: '대화와 같은 언어'(기본), 한국어, English, 日本語, 中文.
- 예: 영어 회의를 한국어로 요약하려면 '한국어'. **대화 언어**(받아쓰기 언어)와는 따로 정합니다.

## 문제가 생기면
- **점검 탭 → 지금 점검**: 엔진·도구·AI 로그인·권한을 확인합니다.
- **엔진 다시 설치**: 엔진이 꼬였을 때.
- **로그 파일 열기**: `~/Library/Logs/dji2note.log`
- "확인할 수 없음" 경고: 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**.
- 그래도 안 되면 정보 탭의 **문의하기**로 알려 주세요.
